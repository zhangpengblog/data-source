收货后必做的四步验证（24 小时内完成，留退货窗口）

  1. 先看针脚。AM4 是 PGA，针脚在 CPU 上。对着光看是否整齐、有无弯曲倒伏。这一步必须在装任何东西之前做 —— 一旦压杆压下再发现弯针，责任就说不清了。
  2. 看顶盖。字迹应清晰锐利、深浅一致。若有打磨痕迹、字迹发虚或与边缘不平行，可能是重印件。
  3. 装机点亮，进 BIOS 核对：型号显示「AMD Ryzen 7 5700G」、8 核 16 线程、L3 缓存 16MB。
  4. 重点验证核显。你整套转码方案都依赖 Vega 8，这一步不能省 —— 用 GPU-Z 或 HWiNFO 确认核显为 Radeon Vega 8、8 个 CU。CPU 能亮但核显有问题，对你这台机器等于废件。

再加两个确认动作

  • 跑一次性能基准。CPU-Z 参考：单核约 600–640、多核约 5,800–6,200（Cinebench R23 多核参考约 13,900）。明显偏低说明是问题件或降频件。
  • 压力测试 15–30 分钟，看温度曲线是否正常、会不会突然降频。这同时验证了散热安装和芯片健康度。

交易保障建议：优先走闲鱼「验货宝」或约定当面验；收货当天完成上述验证；聊天记录里让对方明确承诺「核显正常、无弯针、非打磨件」，出问题时有据可依。
你只需要 1–2 路转码，5700G 的性能对你完全够用 —— 所以不必为「全新未拆」多付几百块，但也不要为省钱去买低于 ¥700 的问题件。

01阶段 1 · 拆旧件

⚠️ 风险点 1：AM4 拆散热器可能把 CPU 一起拔出来。

AM4 是 PGA 封装 —— 针脚在 CPU 上，插槽里是孔。硅脂用久了会干结，散热器和 CPU 会黏在一起。如果你直接往上硬拔，很可能把 CPU 从插槽里拽出来，而 AM4 的压杆是锁死状态，强行带出会弯针。

正确的拆除顺序

  1. 先让硅脂软化。装回原配置，开机跑 5 分钟（进 BIOS 待着或跑个轻负载），让 CPU 发热把硅脂焐软，再关机断电。
  2. 拔掉电源线，按几次开机键放电。
  3. 拆 1660S 显卡。拧下挡板螺丝，按下 PCIe 插槽末端的卡扣，垂直取出。妥善收好 —— 它要出掉。
  4. 拆散热器时先"扭"不要"拔"。松开扣具后，用手握住散热器轻轻左右旋转，感觉到松动后再垂直取下。绝不要直接往上拉。
  5. 如果发现 CPU 被带出来了：立刻停手，不要翻转、不要碰针脚。用指甲或塑料片从侧面把 CPU 从散热器底面平推下来，或者用牙线/细线从缝隙穿过拉锯式分离。
  6. 取下 5800X3D，针脚朝上放在原装塑料托里（或插回原盒的防静电海绵），单独收好 —— 它要出掉，成色直接影响价格。
  7. 清理硅脂。用无绒布蘸无水酒精，把散热器底面和 CPU 表面的旧硅脂擦干净（散热器要留用的话，AXP90 用不上，但卖掉或备用也擦干净）。

验收点：5800X3D 已取下、针脚完好无损；1660S 已取下、金手指无划伤；主板 AM4 插槽内没有硅脂残渣。

02阶段 2 · 装 CPU 与散热

装 5700G

  1. 把 AM4 插槽的压杆完全抬起（垂直方向）。
  2. 核对对齐标记：CPU 一角有个小三角，插槽一角也有个三角，两个对齐。
  3. 垂直放下 CPU，它会靠自身重量自然落到位。如果放不平，说明方向错了，拿起来重新对 —— 千万不要用力按。
  4. 压杆下压并卡入固定钩。这一步会有一点阻力，属于正常。

装利民 AXP90-X47

  1. 先拆除主板原装的塑料扣具模块（AM4 主板 CPU 两侧那两块黑色塑料卡扣），保留主板背面的金属背板。
  2. 按利民说明书装扣具：AM4 用附带的扣具件 + 螺丝，直接拧在主板自带背板上。
  3. 涂硅脂：5700G 是 65W，用量很少。在 CPU 中央挤黄豆粒大小一点即可，装散热器时压力会自然摊开。不要涂满整片，也不要涂抹太厚。
  4. 对准扣具放下散热器，对角交替、分次拧紧螺丝（每次拧两圈换对角），避免压偏。
  5. 插上 CPU 风扇插头到主板的 CPU_FAN 接口（务必插这个口，否则可能报风扇错误无法开机）。

参考：盒装幽灵散热器能用吗？—— 能用，但散片不带

说明：你已决定买散片，而散片不带任何散热器，所以这一段对你只是参考 —— 除非你手上恰好有闲置的幽灵散热器，那可以用它省下 ¥169。

5700G 盒装附带的是一颗 AMD Wraith Stealth（幽灵）。各来源交叉验证后的规格如下：

结论：能用，能省 ¥169。而且安装比 AXP90 更简单 —— 弹簧螺丝直接拧在主板原装背板上，不需要拆主板那两块塑料扣具。加上 C6 是四面网孔、机箱里只有 CPU 一个热源（65W），实际散热条件比典型机箱宽松得多。

但要知道它的三处妥协：

  • 噪音 —— 纯铝无热管、风扇可到 2700 RPM，满载约 30 dB(A)。对一台 7×24 放在家里的机器，持续转码时的噪音是真实存在的问题。
  • 余量小 —— 它按 65W 设计，而 5700G 的 PPT 上限约 88W，长时间满载会贴着它的极限。
  • 积尘后更吃力 —— 7×24 的机器散热器会积尘，本来余量小的话，几个月后风扇更容易跑满转速。

建议：先用原装，实测后再决定要不要换。装机时先用盒装幽灵（安装更简单，还预涂了硅脂），跑起来之后实地听噪音、看温度 —— 待机 40–50°C、转码不超过 80°C 且噪音能接受，就直接省下 ¥169；觉得吵或温度偏高，再换 AXP90-X47。此时硅脂是新涂的、没干结，拆装很容易，不会有 AM4 黏住的风险，而且 AXP90 自带的硅脂仍可用。把决定放到有实测数据之后，比现在猜更靠谱。

验收点：散热器底面与 CPU 完全贴合无缝隙，螺丝已对角拧紧，风扇能自由转动不碰线。此阶段先不要把主板装进机箱 —— 后面还有内存和固态要装。

03阶段 3 · 装内存与固态

内存

你的内存是 32GB DDR4，先确认是两条 16GB 还是四条 8GB：

  • 如果是 2×16GB：插在 第 2 和第 4 个插槽（从 CPU 侧数起，主板通常标为 A2 / B2），这样能稳定跑 DDR4-3200 双通道。
  • 如果是 4×8GB：AM4 平台插满四条时，内存控制器压力大，频率往往跑不到 3200（常见降到 2666–2933）。建议只插两条（同样选 A2 / B2），把频率拉回 3200 —— 对核显转码更有利。剩下的两条留着备用或出掉。

安装方法：掰开插槽两端的卡扣，对准防呆缺口，双手拇指按住内存两端同时用力下压，听到"咔"两声即到位。

M.2 固态（系统盘）

技嘉 B450M AORUS ELITE 有两个 M.2 插槽：一个支持 22110 规格、直连 CPU；另一个只支持 2280、走芯片组。系统盘优先插直连 CPU 的那个（通常在 CPU 下方，速度更快）。

  • 拧下散热片螺丝（如果有），取出散热片
  • 把 M.2 以约 30° 斜角插入插槽到底
  • 用螺丝固定尾端，再装回散热片

验收点：内存两侧卡扣已完全扣合；M.2 尾端螺丝已固定、散热片已装回。

04阶段 4 · 换机箱与走线

装机顺序（在这个大小里顺序很重要）

  1. 先把电源装进 C6。电源位在顶部后方。C6 的电源限长 185mm，你的 GP600P 只有 140mm，空间充裕。电源风扇朝下（朝机箱内部）或朝上（朝顶板网孔）都可以，后者散热更好。
  2. 装主板。装好铜柱（C6 出厂已预装对应 M-ATX 位置的铜柱，核对一下），把已装好 CPU/散热器/内存/固态的主板放进去，拧上螺丝。
  3. 装风扇。顶部 1× 12cm（出风，风往外吹）、底部 1× 12cm（进风，风往内吹）。底部风扇注意别和主板或线材打架。
  4. 走线。见下方专项说明。
  5. 接前面板线。前面板开关/指示灯接主板 F_PANEL；前置 USB-A 接 USB 3.1 Gen 1 header（19-pin 插座）。

非模组电源的走线方案

你的 GP600P 是非模组，线材全部直出且偏长（24pin 550mm、CPU 8pin 600mm），同时带着 5× SATA + 3× 大4pin + 2× PCIe 8pin —— 这些你全都用不到（硬盘在独立柜、不插显卡），但拆不掉。

处理思路：把用不到的线束捆起来，塞进空着的显卡位。

  1. 先把必须用的两根接好：24-pin 主板供电、8-pin CPU 供电（从主板左上角走，尽量贴着主板边缘绕过散热器）。
  2. 其余所有用不到的线（SATA、大4pin、PCIe），用魔术贴扎带捆成一整束，不要分成多小捆 —— 一整束比几小束好塞。
  3. 把这束线塞进机箱下部（原显卡位）的空隙，尽量贴着机箱侧板，不要横穿机箱中部。
  4. 关键：不要挡住 CPU 散热器上方的空间。下压式散热器需要从上方吸风，线束压在上面会直接影响散热效率。

C6 是四面网孔设计，散热条件本来就宽松（机箱内只有 65W 的 CPU 一个热源），所以走线的主要目标是整齐和不挡风，不必追求极致。

已知项：前置 Type-C 接不了。C6 的前置 Type-C 是 20-pin Type-E 接口，而技嘉 B450M AORUS ELITE 没有这个插座（Type-E 是 X570/B550 之后才普及的）。把这条线单独捆好塞起来不接即可，前置 USB-A 可以正常使用。不要为此专门买转接线 —— 主板前置接口只有 5Gbps，转接也达不到 C6 标称的 10Gbps。

验收点：所有线束已固定不松动；CPU 散热器上方无遮挡；机箱内没有散落的螺丝；侧板能顺利合上（合不上就重新理线，不要硬压）。

05阶段 5 · 点亮与 BIOS 设置

首次点亮

接好显示器（插主板的核显 HDMI 或 DVI 口）、键鼠、电源线。开机后立刻连续按 Del 键进入 BIOS。

如果显示器无信号：先确认视频线插在主板的核显接口上（不是显卡位），然后检查内存是否插到底、CPU 8-pin 供电是否接好。

BIOS 必设项（逐项照做）

设置项设为为什么必要性
SVM Mode（AMD 虚拟化）Enabled跑虚拟机的前提，不开虚拟机功能无法启动必须
XMP / DOCPProfile 1让内存跑到标称的 DDR4-3200，核显共享带宽更高建议

技嘉 B450 的 BIOS 里，SVM Mode 通常在 M.I.T. → Advanced CPU Settings 或 Chipset 菜单下；显示输出与 UMA 在 Settings → IO Ports 或 Peripherals 下。不同 BIOS 版本菜单名可能略有差异，以实际界面为准。

设置完成后按 F10 保存并重启，再次进入 BIOS 确认设置已生效。

验收点：BIOS 主界面能正确识别「AMD Ryzen 7 5700G」；SVM Mode 显示 Enabled；内存频率显示 3200MHz（或你插的条数对应的频率）。

06阶段 6 · 安装飞牛 OS

制作启动盘

  1. 在另一台电脑上打开 Rufus，选择你的 U 盘
  2. 选择已下载的飞牛 OS ISO 文件
  3. 分区类型选 GPT，目标系统选 UEFI（与前面 BIOS 里关掉 CSM 对应）
  4. 开始写入，等待完成

安装系统

  1. U 盘插到新主机，开机按 F12（技嘉的启动菜单键）选择从 U 盘启动
  2. 进入飞牛 OS 安装向导，安装目标盘选择你的 M.2 固态 —— 这一步务必确认，别选错盘
  3. 按向导完成安装，重启后拔出 U 盘
  4. 主机接入网线，在浏览器访问安装时显示的 IP 地址，进入飞牛 OS 后台

飞牛 OS 基于 Debian 内核，支持 x86 硬件，可以灵活扩展外部存储。安装细节以官网文档为准。

验收点：能在浏览器打开飞牛 OS 后台并登录；系统信息里 CPU 显示为 8 核 16 线程；挂载的独立硬盘柜能被系统识别。

07阶段 7 · 开启虚拟化能力

飞牛 OS 内置「虚拟机」应用，支持 Q35 主板类型、UEFI 固件、VNC 远程访问，也支持 PCI / USB 直通。你要跑两台桌面虚拟机，用 VNC 访问 —— 这些能力原生就有。

先验证 CPU 虚拟化是否生效

通过 SSH 登录飞牛 OS（用户名 admin，与后台同一个密码），然后：

sudo -i
# 输入密码后提示符变为 root
dmesg | grep -e DMAR -e IOMMU

如果输出里能看到 AMD-Vi: IOMMU enabled 之类的字样，说明底层已就绪。若什么都没输出，回 BIOS 确认 SVM Mode 已开启。

关于硬件直通（你暂时用不到）

飞牛的虚拟机应用里有一个「硬件直通」开关（虚拟机应用 → 硬件 → 硬件直通 → 开启）。但你的方案里不需要它 —— 你不插显卡、硬盘在独立柜，没有任何 PCI 设备要直通。不要为了"开全功能"去折腾直通，官方明确提示直通有稳定性风险（可能导致宿主或虚拟机崩溃），对一台 7×24 的 NAS 不划算。

验收点：SSH 能正常登录；能打开「虚拟机」应用界面。

08阶段 8 · 部署 Docker 与 Jellyfin

安装 Docker

  1. 飞牛 OS 后台 → 左侧 「应用中心」
  2. 搜索 Docker，找到「Docker 容器引擎」，点击安装
  3. 等待 2–3 分钟，安装完成后在「已安装」页可以看到 Docker 图标
  4. 如果镜像拉取慢，在 Docker 设置里配置国内镜像加速源

建目录习惯（强烈建议）

先在存储里建一个专门的 Docker 文件夹（例如 /vol1/1000/docker/），每个应用一个子文件夹，把 compose 配置和持久化数据都放在里面。好处是备份、升级、卸载都干净，不留残留。

部署 Jellyfin

推荐用 Docker Compose 部署（比一键安装更好管理）。核心是把核显设备映射进容器：

version: '3.8'
services:
  jellyfin:
    image: jellyfin/jellyfin
    container_name: jellyfin
    network_mode: host
    volumes:
      - ./config:/config
      - ./cache:/cache
      - /你的影片目录:/media:ro
    devices:
      - /dev/dri:/dev/dri        # 核显直通给容器，硬件转码的关键
    restart: unless-stopped

转码设置（这是你的核心需求）

设置项值说明
硬件加速VAAPIAMD 核显的正确方式
VA-API 设备/dev/dri/renderD128
HEVC 10bit 解码勾选最关键的一项，4K 片源全靠它
输出编码器HEVC 优先，同时启用 H.264AMD 的 H.264 编码器质量最差，HEVC 明显更好且再省 30–50% 码率；两个都开让服务端按客户端自动选
远程连接最大码率约 800 kbps外网自动转码、局域网保持直通，正好匹配你的用法
色调映射关闭你没有 HDR 片源，而它是 AMD 核显最吃力的环节

关于 360p 的降采样：4K 到 360p 是横竖各 6 倍，硬件缩放单元单级处理会在细密纹理上产生摩尔纹。可在转码参数里开启抗锯齿标志；如果还是明显，改成两级缩放（你只 1–2 路，扛得住）。

验收点：用一部 1080p 和一部 4K 片源各播一次，播放界面能看到「转码」标志；在飞牛后台看 CPU 占用，4K 转 360p 时 CPU 不应持续跑满（跑满说明没走硬解）。建议把实测的帧率和 CPU 占用记下来，这是唯一没法纸面确认的部分。

09阶段 9 · 创建两台虚拟机

打开飞牛 OS 的「虚拟机」应用 → 新建。两台机器用同样的模板，参数不同：

vCPU42

网卡E1000E1000
访问方式创建后点右侧「开机」，再用页面上的 VNC 入口访问桌面

分配逻辑：宿主自己要留 2–4 个核心给 Jellyfin 转码和文件服务，所以两台虚拟机加起来不要超过 6 个 vCPU。内存方面宿主留 8GB、系统缓存 12GB 左右。

验收点：两台虚拟机都能开机并通过 VNC 看到桌面；宿主的 CPU 和内存占用在可接受范围（内存不要持续接近 100%，那是换页的信号）。
